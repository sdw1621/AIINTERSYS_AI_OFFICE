# 🏢 AIINTERSYS AI OFFICE

Claude 에이전트 팀이 **가상 사무실에서 실제로 협업하는 모습**을 보여주는 웹앱입니다.
업무를 지시하면 팀장이 일을 나눠 팀원에게 맡기고, 팀원들은 조사·기획·작성·검토를 거쳐 최종 결과물을 만듭니다.
그 과정이 사무실 화면에서 캐릭터 이동, 말풍선, 모니터 상태로 실시간 표시됩니다.

## 실행 방법

```bash
npm install
npm start
```

브라우저에서 http://localhost:3000 을 엽니다.

- **데모 모드**: API 키 없이 정해진 대본으로 사무실 흐름만 보여줍니다. 비용이 들지 않습니다.
- **실제 AI 모드**: `.env.example`을 `.env`로 복사하고 `ANTHROPIC_API_KEY`를 넣은 뒤 서버를 다시 시작하면 활성화됩니다. 실제 Claude API 비용이 발생하며, 화면 오른쪽 위에 예상 비용이 표시됩니다.

## 구조

```
server.js            Express 서버 · 작업 생성 API · 실시간 이벤트(SSE)
src/agents.js        팀원 정의(이름·역할·책상 위치)와 시스템 프롬프트
src/orchestrator.js  실제 모드: 팀장이 delegate_task 도구로 팀원을 호출하는 에이전트 루프
src/demo.js          데모 모드: 같은 이벤트를 대본대로 재생
src/jobs.js          작업별 이벤트 기록 · 구독 관리
public/              사무실 화면 (HTML/CSS/JS, 빌드 과정 없음)
```

### 동작 방식
1. 팀장(Claude)은 `delegate_task(agent, instruction)` 도구 하나를 가지고 있습니다. 서로 독립적인 업무는 한 번에 여러 개를 호출해 **동시에** 진행합니다.
2. 서버는 도구 호출을 받아 해당 팀원(별도의 Claude 호출, 역할별 시스템 프롬프트)을 실행하고 결과를 팀장에게 돌려줍니다. 팀원별 대화 기록이 유지되어, 같은 팀원에게 다시 맡기면 이전 작업을 기억합니다.
3. 리서처는 Claude의 웹 검색 도구를 사용합니다. 조직 설정에서 웹 검색이 꺼져 있으면 검색 없이 진행합니다.
4. 모든 과정(생각 요약·작성 중인 글·검색어·위임·보고)이 이벤트로 브라우저에 스트리밍되어 사무실 애니메이션으로 표시됩니다.

기본 모델은 `claude-opus-5`이고, 적응형 사고(adaptive thinking)를 사용합니다. 설정은 `.env.example`을 참고하세요.
