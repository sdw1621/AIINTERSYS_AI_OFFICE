# 🏙️ AIINTERSYS AI TOWER

Claude 에이전트 **15명 조직**이 3층짜리 가상 타워에서 **실제로 협업하는 모습**을 보여주는 웹앱입니다.
업무를 지시하면 총괄 본부장이 팀장들에게 일을 나누고, 팀장은 다시 팀원 2명에게 맡긴 뒤 팀 결과를 보고합니다.
첨부한 자료(PDF·Word·hwpx·엑셀·CSV·이미지)는 누구나 꺼내 읽을 수 있고, 결과는 Neon DB 보고함에 쌓입니다.

## 조직과 층

| 층 | 팀 | 사람 |
|---|---|---|
| 3F | 총괄 본부 | 김도윤 본부장 · 윤서아 비서 · 강민재 전략매니저 |
| 2F | 리서치팀 / 기획팀 | 이서연 팀장 · 오태윤 · 문하린 / 박준호 팀장 · 류건우 · 홍다인 |
| 1F | 콘텐츠팀 / 품질검토팀 | 최하은 팀장 · 장예린 · 백승우 / 정유진 팀장 · 권태현 · 노은채 |

모두 AI로 만든 가상 인물(실존 인물 아님)이며, 경력·성격·말투가 각자의 시스템 프롬프트에 들어갑니다. 프로필은 `src/agents.js`에서 바꿉니다.

## 화면

- **📊 모니터링(첫 화면)**: 진척도·단계, 지표, 팀별 조직 현황, 팀별 간트 타임라인, 시간순 진행 기록과 최종 결과
- **🏙️ 타워**: 미래형 유리 타워 3D. "전체 타워"에서 층을 눌러 들어가면 위층을 걷어내고 그 층을 보여 줍니다. 다른 층으로 가는 사람은 유리 엘리베이터를 탑니다. "일 따라가기"를 켜 두면 일이 진행되는 층으로 화면이 따라갑니다.
- **🗂️ 보고함**: 공용(Neon DB) + 이 브라우저 보고서. **▶ 모니터링에서 다시 보기**로 저장된 작업 기록을 진척도·타임라인·타워 애니메이션으로 재생합니다.
- **🔊 음성 알림**: 본부장 분배, 팀별 보고, 팀별 작업 완료, 전체 완료 시 알림음과 한국어 음성으로 요약해 알려 줍니다.

## 업무를 돌리는 세 가지 방법

| 방법 | 설명 | 비용 |
|---|---|---|
| 데모 | 정해진 대본으로 흐름만 보여 줌 (첨부 자료 이름·앞부분만 사용) | 없음 |
| 실제 AI | 서버의 `ANTHROPIC_API_KEY`로 15명이 실제로 일함 (`OFFICE_PASSCODE` 필요) | API 사용량 |
| 지피·구독 | claude.ai 대화에서 Claude가 역할 흐름대로 작업한 결과와 타임라인을 DB에 등록 → 보고함에서 다시 보기 | 구독 범위 |

> 구독(Pro·Max) 로그인으로 이 웹앱의 API 호출을 대신할 수는 없습니다(Anthropic 정책). 웹앱의 자동 실행은 API 키를 씁니다.

## 실행 방법

```bash
npm install
npm start
```

브라우저에서 http://localhost:3000 을 엽니다.

- **데모 모드**: API 키 없이 정해진 대본으로 사무실 흐름만 보여줍니다. 비용이 들지 않습니다.
- **실제 AI 모드**: `.env.example`을 `.env`로 복사하고 `ANTHROPIC_API_KEY`를 넣은 뒤 서버를 다시 시작하면 활성화됩니다. 실제 Claude API 비용이 발생하며, 화면 오른쪽 위에 예상 비용이 표시됩니다.

## Vercel 배포 · 환경변수

| 변수 | 용도 |
|---|---|
| `DATABASE_URL` | Neon 보고함 (없으면 브라우저 저장만) |
| `OFFICE_PASSCODE` | 공개 배포에서 실제 AI 모드·공용 보고함 접속 코드 |
| `ANTHROPIC_API_KEY` | 실제 AI 모드 |
| `CLAUDE_MODEL`, `MANAGER_EFFORT`, `LEAD_EFFORT`, `WORKER_EFFORT` | 모델·사고 깊이 (비용 조절) |

### 배포 방식

`main` 브랜치에 푸시하면 Vercel이 자동 배포합니다. `server.js`가 Express 앱을 export하고, `public/`은 CDN이 직접 서빙합니다.

- 환경변수 없이 배포하면 **데모 모드만** 동작합니다.
- 실제 AI 모드를 켜려면 Vercel 프로젝트 환경변수에 `ANTHROPIC_API_KEY`와 `OFFICE_PASSCODE`(접속 코드)를 **둘 다** 넣고 재배포합니다. 공개 URL이라 접속 코드 없이는 실제 모드가 꺼지도록 되어 있습니다. 실제 모드를 고르면 브라우저가 접속 코드를 한 번 묻습니다.
- 함수 최대 실행 시간은 `vercel.json`에서 300초로 잡혀 있습니다. 실제 모드 작업이 이보다 길면 중간에 끊기므로, 필요하면 `MAX_MANAGER_TURNS`나 effort를 낮추세요.

## 구조

```
server.js            Express 서버 · /api/run(NDJSON 스트리밍) · /api/reports(Neon 보고함)
src/agents.js        15명 조직(팀·층·상하관계·책상 위치)과 역할별 시스템 프롬프트
src/orchestrator.js  실제 모드: delegate_task(부하에게 위임)·read_material(자료 열람) 재귀 에이전트 루프
src/materials.js     첨부 자료 정리 · 나눠 읽기
src/demo.js          데모 모드: 같은 이벤트를 대본대로 재생
src/db.js            Neon 보고함 저장·조회
public/app.js        화면 전환 · 모니터링(진척도·간트) · 보고함 · 다시 보기
public/materials.js  브라우저에서 PDF·Word·hwpx·엑셀·이미지 텍스트 추출
public/office3d.js   3층 타워 · 엘리베이터 · 캐릭터 애니메이션 (Three.js)
public/voice.js      단계 완료 음성 알림
```

### 동작 방식
1. 본부장은 팀장 4명과 본부 스태프 2명에게, 팀장은 팀원 2명에게 `delegate_task`로 일을 맡깁니다. 독립적인 일은 동시에 진행합니다.
2. 모든 사람이 `read_material`로 첨부 자료를 쪽 단위로 꺼내 읽고, 리서치팀원은 웹 검색도 씁니다.
3. 모든 과정이 이벤트로 브라우저에 스트리밍되어 모니터링과 타워 애니메이션으로 표시되고, 끝나면 보고함(DB)에 저장됩니다.
