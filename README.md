# 🏙️ AIINTERSYS AI TOWER

AI인터시스의 **실제 프로젝트 · 사람 · 일정**을 한눈에 보는 웹앱입니다.
프로젝트 하나가 타워의 층 하나이고, 구글 캘린더 일정에 따라 사람이 엘리베이터를 타고 그 층으로 이동합니다.

## 화면

- **📊 모니터링**: 지금/다음 일정, 프로젝트 카드(과제명·담당·일정 진행·다음 일정), 프로젝트×날짜 일정 타임라인, 다가오는 2주 일정, 사람별 현재 위치
- **🏙️ 타워**: 5층 유리 타워 3D. 일정 칸을 누르면 그 시각으로 이동해 사람들이 엘리베이터를 타고 해당 층으로 갑니다.
- **🗂️ 보고함**: 프로젝트 분석·정리 자료 (Neon DB)
- **🔊 음성 알림**: 일정 시작 10분 전과 시작할 때 알림음 + 한국어 음성

## 일정 (구글 캘린더)

- `GCAL_ICS_URL`(구글 캘린더 → 설정 → 캘린더 통합 → **iCal 형식의 비공개 주소**)을 넣으면 접속할 때마다 최신 일정을 읽습니다(5분 캐시, 반복 일정·예외 반영).
- 주소가 없으면 DB(`office_events`)에 동기화해 둔 일정을 씁니다.
- 일정 제목·설명에 프로젝트 이름(KRISO/선박해양, 한국몰드, 탑아이앤디, DnK/디엔케이, 소상공인)이 있는 일정만 화면에 나옵니다. **나머지 개인 일정은 서버 밖으로 나가지 않습니다.**

## 단톡방 · AI 음성 회의

- **단톡방 DB**: 카카오톡 '대화 내보내기' .txt를 모니터링 화면의 「대화 파일 올리기」로 올리면 Neon DB에 쌓인다(중복은 자동으로 건너뜀). 업무 보드와 구글 시트(`/api/sheet/<탭>.csv?key=SHEET_EXPORT_KEY`, IMPORTDATA)가 같은 데이터를 보여 준다.
- **자동 수집**: PC에서 `tools/kakao_push.py`를 예약 실행하면 `X-Import-Key: IMPORT_KEY`로 같은 경로에 올린다.
- **AI 음성 회의**: 타워의 「🎙 AI 음성 회의」 → 그날 대화를 담당자별로 나눈 대본을 팀원들이 서로 다른 목소리(브라우저 내장 음성)로 읽는다. 회의 중 글이나 마이크로 끼어들면 관련 담당자가 답한다.
- **LLM**: `LLM_BASE_URL`(OpenAI 호환, 예: 로컬 Ollama `http://…/v1`)과 `LLM_MODEL`을 넣으면 대본·답변을 LLM이 만든다. 없으면 대화 원문에서 핵심 문장을 고르는 규칙 기반으로 동작한다(비용 0).

## 보안

실제 사람·일정이 담기므로 모든 데이터 API(`/api/office`, `/api/reports`)는 접속 코드(`OFFICE_PASSCODE`)가 있어야 열립니다. 공개 배포에 코드가 없으면 데이터 API는 닫힙니다.

## 실행

```bash
npm install
cp .env.example .env   # OFFICE_PASSCODE, GCAL_ICS_URL, DATABASE_URL
npm start              # http://localhost:3000
```

`main`에 푸시하면 Vercel이 배포합니다. 환경변수를 바꾸면 다시 배포해야 반영됩니다.
