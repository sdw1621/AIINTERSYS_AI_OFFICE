# 🏢 AIINTERSYS AI OFFICE

Claude 에이전트 팀이 **가상 사무실에서 실제로 협업하는 모습**을 보여주는 웹앱입니다.
업무를 지시하면 팀장이 일을 나눠 팀원에게 맡기고, 팀원들은 조사·기획·작성·검토를 거쳐 최종 결과물을 만듭니다.
그 과정이 **3D 사무실**에서 캐릭터 이동, 말풍선, 모니터 불빛으로 실시간 표시됩니다.

- Three.js로 옥상 사무실(유리 난간, 유리벽 팀장실과 로고 벽, 회의 테이블, 팀별 구역, 카페 바, 라운지, 오락기, 책장, 화이트보드, 노을과 도시 야경)과 캐릭터를 코드로 직접 모델링했습니다. 외부 3D 파일이 필요 없습니다.
- 캐릭터는 걷기·타이핑·턱 괴고 생각하기·두리번거리며 검색하기·서류 건네기 동작을 하고, 모니터와 발밑 링이 상태 색(생각=보라, 검색=파랑, 작성=초록)으로 빛납니다.
- 마우스 드래그로 회전, 휠로 확대, "입체/정면/위에서" 버튼으로 시점을 바꿀 수 있습니다.

## 화면 구성

상단 메뉴로 세 화면을 오갑니다. 한 페이지 안에서 바뀌므로 화면을 옮겨도 진행 중인 작업은 끊기지 않습니다. 업무 지시창은 모든 화면 아래에 고정되어 있습니다.

- **모니터링 (첫 화면)**: 전체 진척도와 단계(업무 접수 → 팀장 분배 → 팀원 작업 → 최종 정리 → 완료), 경과 시간·위임 업무·검색·비용 지표, 팀원별 현재 상태 카드, 팀원별 **간트 타임라인**(생각·검색·작성·보고 대기 구간과 📋지시·📄보고·🔍검색 표시), 시간순 진행 기록과 최종 결과
- **사무실**: 노을 지는 옥상 사무실을 아이소메트릭 3D로 보여 줍니다. 팀별 색 구역·간판, 팀장실, 카페 바, 라운지, 게임 코너가 있고 캐릭터가 실제로 걸어 다니며 지시·보고합니다.
- **보고함**: 완료된 결과를 이 브라우저에 최근 30건까지 저장합니다. 복사, .md 저장, 같은 업무 다시 지시, 삭제가 가능합니다. (서버 DB가 아니라 브라우저 저장소라 기기·브라우저마다 따로입니다.)

### 음성 알림
단계가 끝날 때마다 알림음과 함께 한국어 음성(가능하면 여성 음성)으로 "누가 무엇을 마쳤는지"와 결과 한두 문장을 읽어 줍니다. 팀장 분배 완료, 팀원별 완료, 팀원 작업 단계 완료, 전체 완료 시점에 알립니다. 브라우저 내장 음성 합성을 쓰므로 비용이 없고, 상단 🔊 버튼으로 끌 수 있습니다.

## 실행 방법

```bash
npm install
npm start
```

브라우저에서 http://localhost:3000 을 엽니다.

- **데모 모드**: API 키 없이 정해진 대본으로 사무실 흐름만 보여줍니다. 비용이 들지 않습니다.
- **실제 AI 모드**: `.env.example`을 `.env`로 복사하고 `ANTHROPIC_API_KEY`를 넣은 뒤 서버를 다시 시작하면 활성화됩니다. 실제 Claude API 비용이 발생하며, 화면 오른쪽 위에 예상 비용이 표시됩니다.

## Vercel 배포

`main` 브랜치에 푸시하면 Vercel이 자동 배포합니다. `server.js`가 Express 앱을 export하고, `public/`은 CDN이 직접 서빙합니다.

- 환경변수 없이 배포하면 **데모 모드만** 동작합니다.
- 실제 AI 모드를 켜려면 Vercel 프로젝트 환경변수에 `ANTHROPIC_API_KEY`와 `OFFICE_PASSCODE`(접속 코드)를 **둘 다** 넣고 재배포합니다. 공개 URL이라 접속 코드 없이는 실제 모드가 꺼지도록 되어 있습니다. 실제 모드를 고르면 브라우저가 접속 코드를 한 번 묻습니다.
- 함수 최대 실행 시간은 `vercel.json`에서 300초로 잡혀 있습니다. 실제 모드 작업이 이보다 길면 중간에 끊기므로, 필요하면 `MAX_MANAGER_TURNS`나 effort를 낮추세요.

## 구조

```
server.js            Express 서버 · 업무 실행 API(/api/run, 이벤트를 NDJSON으로 스트리밍)
src/agents.js        팀원 정의(이름·역할·책상 위치)와 시스템 프롬프트
src/orchestrator.js  실제 모드: 팀장이 delegate_task 도구로 팀원을 호출하는 에이전트 루프
src/demo.js          데모 모드: 같은 이벤트를 대본대로 재생
src/jobs.js          작업 하나의 이벤트 기록 · 구독 관리
public/app.js        화면 전환 · 모니터링(진척도·타임라인) · 보고함
public/office3d.js   3D 사무실 · 캐릭터 · 애니메이션 (Three.js)
public/voice.js      단계 완료 음성 알림 (알림음 + 한국어 음성 합성)
public/              화면 (HTML/CSS/JS, 빌드 과정 없음)
```

### 동작 방식
1. 팀장(Claude)은 `delegate_task(agent, instruction)` 도구 하나를 가지고 있습니다. 서로 독립적인 업무는 한 번에 여러 개를 호출해 **동시에** 진행합니다.
2. 서버는 도구 호출을 받아 해당 팀원(별도의 Claude 호출, 역할별 시스템 프롬프트)을 실행하고 결과를 팀장에게 돌려줍니다. 팀원별 대화 기록이 유지되어, 같은 팀원에게 다시 맡기면 이전 작업을 기억합니다.
3. 리서처는 Claude의 웹 검색 도구를 사용합니다. 조직 설정에서 웹 검색이 꺼져 있으면 검색 없이 진행합니다.
4. 모든 과정(생각 요약·작성 중인 글·검색어·위임·보고)이 이벤트로 브라우저에 스트리밍되어 사무실 애니메이션으로 표시됩니다.

기본 모델은 `claude-opus-5`이고, 적응형 사고(adaptive thinking)를 사용합니다. 설정은 `.env.example`을 참고하세요.
